# Badge

A small pill for counts and state. Always text, optionally with a 16px icon or the `gold` dot.

- default: counts ("3 Wünsche").
- `wi-badge--red`: waiting or locked states.
- `wi-badge--green`: done states ("Gezogen").
- `wi-badge__dot`: the gold sparkle for the countdown only.

State is never carried by color alone; the word says it.
