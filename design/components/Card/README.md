# Card

A card groups one topic on `surface`. The consumer provides the heading (`wi-card__title`), an optional line of `wi-card__text`, and any content below.

- `wi-card`: white `surface-raised`, 1px `border`, `radius-lg`, `shadow-card`. The default.
- `wi-card--red` / `wi-card--green`: flat tinted cards for a hero message or a confirmation; no shadow.
- `wi-card--media`: puts a mascot `<img>` (96px wide) left of the text. Use Kitti only in tinted cards.

Don't nest cards, and don't add a colored left border.
