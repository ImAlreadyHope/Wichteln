# Countdown

The home screen's reveal card before the unlock date (20 November, 00:00 Europe/Berlin). Composition inside a `wi-card--red`:

1. `wi-lock__mascot`: Flocke **sleep** pose, 140px.
2. Heading and one line naming the date.
3. `wi-lock__days`: days, hours, minutes in `wi-lock__unit` boxes with tabular numerals.
4. The disabled large primary button with the `lock` icon, so people learn where it will be.

On the unlock date the same card swaps to Flocke **gift**, the button enables, and the countdown disappears.
